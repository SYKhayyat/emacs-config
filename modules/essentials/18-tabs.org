#+TITLE: 27 · Tabs (workspace tab-bar + hydra)
#+PROPERTY: header-args:emacs-lisp :tangle 18-tabs.el :mkdirp yes :comments no

The one tab system in this config is the built-in workspace *tab-bar*, set up in
=05-navigation=: each tab is a complete window layout, so a tab is a *workspace*.
Split the window as much as you like inside a tab and the whole arrangement
belongs to that tab — switching tabs swaps the entire layout at once.  That is
the browser-tab-for-a-workspace model, and it is the natural fit for splits: the
tabs live once, at the top of the frame, instead of every split echoing the same
strip back at you.

Everything inside a workspace — jumping to a buffer, killing one, running
ibuffer — is covered by commands you already have (=C-x b= is
=consult-buffer=).  This module adds the two lifts that make the workspace model
comfortable: one workspace tab per projectile project, and a single discoverable
=hydra= (=C-c T=) that ties workspace switching together with buffer management.

What each thing is, so the keys make sense:
- *Workspace* (tab-bar) = a whole window layout. One per project.
- *Switch buffer* (=C-x b= / hydra _b_) = get to any open file inside a workspace.
- *Kill a buffer* = actually close the file (=C-x k=, or the hydra).

Nothing here duplicates =05-navigation=; it only surfaces and extends it.

* Open a projectile project in its own workspace tab
A fresh workspace tab, switched into a project, and named after it.  Aborting
the picker cleans up the tab.
#+begin_src emacs-lisp
;;; 18-tabs.el --- Workspace tabs + unifying tabs hydra -*- lexical-binding: t; -*-

(defun my/projectile-project-in-new-tab ()
  "Open a projectile project in a brand-new workspace tab named after it."
  (interactive)
  (let ((tab-bar-new-tab-choice t))     ; new tab keeps the current buffer
    (tab-bar-new-tab))
  (condition-case _
      (progn
        (call-interactively #'projectile-switch-project)
        (let ((name (projectile-project-name)))
          (when (and name (not (string-empty-p name)))
            (tab-bar-rename-tab name))))
    (quit (tab-bar-close-tab))))         ; picker aborted -> drop the empty tab
#+end_src

* The tabs hydra — one menu for everything (=C-c T=)
Sticky (pink) so you can step through workspaces with =h/l= repeatedly;
=] [/= and =1-9= make the workspace row behave like the row it is.  The
switch/manage column routes through =consult-buffer= and the kill commands from
=05-navigation=, which is what lets one menu reach everything inside a
workspace.
#+begin_src emacs-lisp
(with-eval-after-load 'hydra
  (defhydra hydra-tabs (:color pink :hint nil)
    "
^Workspaces (tab-bar)^      ^Switch / manage^
^^--------------------------------------------------------
_n_: new workspace          _b_: switch buffer (consult)
_x_: close workspace        _d_: kill this buffer
_]_ next   _[_ prev          _o_: kill other buffers
_r_: rename workspace        _K_: kill buffer + window
_s_: project → new tab        _g_: ibuffer (mass manage)
_1_.._9_: jump to workspace N
"
    ;; Workspaces (tab-bar, built-in)
    ("n" tab-bar-new-tab)
    ("x" tab-bar-close-tab)
    ("]" tab-bar-switch-to-next-tab)
    ("[" tab-bar-switch-to-prev-tab)
    ("r" tab-bar-rename-tab :color blue)
    ("s" my/projectile-project-in-new-tab :color blue)
    ("1" (tab-bar-select-tab 1)) ("2" (tab-bar-select-tab 2))
    ("3" (tab-bar-select-tab 3)) ("4" (tab-bar-select-tab 4))
    ("5" (tab-bar-select-tab 5)) ("6" (tab-bar-select-tab 6))
    ("7" (tab-bar-select-tab 7)) ("8" (tab-bar-select-tab 8))
    ("9" (tab-bar-select-tab 9))
    ;; Switch / manage
    ("b" consult-buffer :color blue)
    ("d" my/kill-current-buffer)
    ("o" my/kill-other-buffers)
    ("K" kill-buffer-and-window :color blue)
    ("g" ibuffer :color blue)
    ("q" nil "quit" :color blue))

  (global-set-key (kbd "C-c T") #'hydra-tabs/body))
#+end_src
