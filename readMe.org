* Introduction

This is a comprehensive guide to a literate Emacs configuration optimized for:

- *Hebrew (RTL) as default*, with seamless switching to English (LTR)
- *Academic document preparation* with LaTeX (LuaLaTeX + Babel), ConTeXt, and Typst
- *Unlimited structure depth* in headings and lists (Org and LaTeX)
- *Nested footnotes* across all three document systems
- *Org-roam* for Zettelkasten-style note-taking with full Hebrew support
- *Seforim library management* for fast searching of large Hebrew text collections
- *PDF annotation* with org-noter integration
- *Bibliography management* with Citar

The configuration is written in literate Org format (=config.org=) and automatically tangles to =config.el= on save.

*** NixOS Module

The Emacs environment is defined in =emacs.nix=. Import it from =configuration.nix=:

#+begin_example
imports = [ ./emacs.nix ];
#+end_example

The module provides:
- All system packages and fonts
- Emacs with Nix-provided packages (jinx, exec-path-from-shell, pdf-tools)
- Plocate service with hourly indexing
- Recoll configuration and systemd timer for periodic indexing
- User membership in =plocate= group
- Environment variables (=DICPATH=, =OSFONTDIR=)
- Seforim directory creation

*** Important: Nix-Provided vs MELPA Packages

Packages provided by Nix must use =:ensure nil= in =config.org=:

| Package | Source | =:ensure= |
|---------|--------|-----------|
| =jinx= | Nix | =nil= |
| =exec-path-from-shell= | Nix | =nil= |
| =pdf-tools= | Nix | =nil= |
| Everything else | MELPA | =t= (default) |

** First Run Tasks

After first launch:

1. Wait for MELPA packages to install (first startup is slow)

2. Install icon fonts:
   : M-x all-the-icons-install-fonts RET

3. Initialize org-roam database:
   : M-x org-roam-db-sync RET

4. Build Seforim indexes (if using Seforim library):
   : M-x seforim-reindex RET

5. Verify tools are available:
   : M-x seforim-status RET

Note: =pdf-tools= is installed via Nix and does not need =M-x pdf-tools-install=. It runs =pdf-tools-install :no-query= automatically.

** Verifying the Installation

After =sudo nixos-rebuild switch= and starting Emacs:

#+begin_src shell
# Verify plocate group membership (re-login after first rebuild)
groups | grep plocate

# Verify recoll config
cat ~/.recoll/recoll.conf

# Verify fonts
fc-list | grep -i "david\|nachlieli\|miriam"

# Verify tools
which plocate fd rg rga recoll typst tinymist lualatex
#+end_src

In Emacs:

#+begin_example
M-x jinx-languages RET        → should show "en he"
M-x seforim-status RET        → should show all tools ✓
C-h v exec-path RET           → should include /run/current-system/sw/bin
#+end_example

Undo history is automatically saved to =~/.emacs.d/undo-tree-history/= and restored when you reopen files. This means you can undo changes from previous sessions.

The configuration maintains large undo limits:

- 120MB strong limit
- 300MB outer limit

* Focused Writing Mode

Focused writing mode centers your text in an 80-column window, removing distractions.

** Keybindings

| Keybinding | Action |
|------------|--------|
| =C-c w= | Toggle focused writing mode |
| =C-c W= | Set custom column width |

** What It Does

When enabled:
- Text is soft-wrapped at 80 columns (no hard line breaks inserted)
- Content is visually centered in the window
- Ideal for prose writing in Org, LaTeX, or Markdown

When disabled:
- Returns to normal full-width editing

** Customizing Width

Press =C-c W= and enter a number to change the column width. Common values:
- =60= - Narrow, very focused
- =80= - Standard (default)
- =100= - Wider, good for code-heavy documents
- =120= - Wide, approaching full screen

* Hebrew and RTL Support

** How Direction Works

The configuration automatically sets text direction based on major mode:

| Mode Type | Default Direction |
|-----------|-------------------|
| Org, LaTeX, ConTeXt, Typst | RTL (Hebrew) |
| Text, Markdown | RTL (Hebrew) |
| Programming modes | LTR (English) |

You can always override manually.

** Switching Languages

| Keybinding | Action |
|------------|--------|
| =F9= | Toggle input method (Hebrew ↔ English keyboard) |
| =C-c d= | Toggle text direction (RTL ↔ LTR) |
| =C-c r= | Force RTL direction |
| =C-c l= | Force LTR direction |
| =C-c D= | Open direction controls hydra menu |

** Visual Indicators

The modeline shows current state:
- =[RTL עב]= — Hebrew mode, right-to-left
- =[LTR EN]= — English mode, left-to-right

The indicator updates only when direction changes (no performance cost).

** Direction Controls Hydra (=C-c D=)

#+begin_example
Direction Controls

r: RTL (Hebrew)    l: LTR (English)    t: Toggle direction
h: Hebrew spell    e: English spell    b: Both languages
B: Toggle bidi     w: Focus writing    W: Set width
q: quit
#+end_example

** Performance Toggle

For very large files (>5MB), expensive features are automatically disabled:
- Jinx spell checking turned off
- Bidi reordering disabled

For manual control:

| Keybinding | Action |
|------------|--------|
| =C-c B= | Toggle bidi reordering on/off |

Re-enable when you need proper RTL display.

** Best Practices

1. *Hebrew documents*: Just start typing. Org, LaTeX, etc. default to RTL.
2. *English documents*: Press =C-c l= to switch to LTR.
3. *Mixed documents*: Use =C-c d= to toggle as needed, or use language environments in LaTeX.
4. *Code*: Automatically LTR in all programming modes.

Jinx is automatically enabled in:
- =text-mode= (and derived modes)
- =org-mode=
- =LaTeX-mode=

** NixOS Requirements

Spell checking requires these packages (provided by =emacs.nix=):
- =enchant2= — spell checking library
- =hunspell= with =en_US= and =he_IL= dictionaries
- =jinx= — Emacs package (provided via Nix, use =:ensure nil=)

The =DICPATH= environment variable is set by =emacs.nix= to point to the Nix-provided dictionaries.

* Nested Footnotes in LaTeX

The =bigfoot= package provides multiple footnote levels. Each level appears in its own *separate block* at the bottom of the page.

** Method 1: Simple Footnotes (Non-Nested)

** Method 2: True Nesting (Footnote Within Footnote)

#+begin_src latex

    This second-level footnote appears in its own separate block.
    It can even contain another level\footnotemarkC{}.
    \footnotetextC{Third level footnote, in its own block.}%

}
#+end_src

** Local Footnotes in ConTeXt

ConTeXt's killer feature: footnotes that appear at the bottom of their *parent footnote*, not at the bottom of the page.

#+begin_src tex
זהו טקסט ראשי.\footnote{
  זוהי הערת שוליים ראשונה.
  \startlocalfootnotes
  מונח כלשהו.\localfootnote{
    הערה מקוננת — מופיעה בתחתית ההערה הראשונה.
    \startlocalfootnotes
    עוד מונח.\localfootnote{
      הערה שלישית — בתחתית ההערה השנייה.
    }
    \placelocalfootnotes
    \stoplocalfootnotes
  }
  \placelocalfootnotes
  \stoplocalfootnotes
}
#+end_src

*Result:*
- Level 1 footnote → bottom of page
- Level 2 footnote → bottom of level 1 block
- Level 3 footnote → bottom of level 2 block

Use =C-c P= then =f= to insert a local footnote structure.

** Use-Package Syntax Reference

#+begin_src emacs-lisp
(use-package package-name
  :ensure t                      ; Install if not present (nil for Nix packages)
  :hook (mode-name . function)   ; Add to mode hook
  :bind (("C-c x" . command))    ; Global keybinding
  :bind (:map mode-map           ; Mode-specific keybinding
         ("C-c y" . command))
  :custom                        ; Set custom variables
  (variable-name value)
  :init                          ; Run BEFORE package loads
  (some-setup-function)
  :config                        ; Run AFTER package loads
  (setq some-variable value)
  :after other-package           ; Load after dependency
  :defer t                       ; Lazy load
  :mode "\\.ext\\'"              ; Associate with file extension
  :diminish                      ; Hide from modeline
  :commands (cmd1 cmd2))         ; Autoload these commands
#+end_src

* Troubleshooting

** Startup Issues

*** Packages Not Installing

#+begin_example
M-x package-refresh-contents RET
#+end_example

*** Slow Startup

First startup is slow due to package installation. If still slow:

1. Check =*Messages*= buffer for errors
2. Run: =emacs --debug-init=
3. Profile: =M-x profiler-start RET RET= ... =M-x profiler-report=

*** Config Changes Not Taking Effect

After editing =config.org=:

1. Delete =~/.emacs.d/config.el=
2. Restart Emacs

Or manually tangle: =M-x org-babel-tangle RET=

*** NixOS: Package Not Found

If Emacs can't find a tool (e.g., =plocate=, =recoll=):

1. Check exec-path:
   : C-h v exec-path RET

2. Ensure =/run/current-system/sw/bin= is in the list

3. If not, restart Emacs after =nixos-rebuild switch=

** Hebrew and RTL Issues

*** Hebrew Not Displaying

1. Check fonts installed:
   #+begin_src shell
   fc-list | grep -i "david\|nachlieli\|miriam"
   #+end_src

2. Check input method:
   : C-h v current-input-method RET

3. Check direction:
   : C-h v bidi-paragraph-direction RET

*** Hebrew Footnotes Showing as LTR in Org

Use =C-c h f= to fix all existing footnotes. New footnotes are fixed automatically.

*** Bidi Performance Issues

Files larger than 5MB automatically disable bidi reordering. For manual control: =C-c B=

** Spell Checking Issues

*** Spell Check Not Working

1. Check enchant2 and dictionaries:
   #+begin_src shell
   echo $DICPATH
   ls $DICPATH
   #+end_src

2. Verify jinx in Emacs:
   : M-x jinx-languages RET

3. Ensure =jinx= uses =:ensure nil= (Nix-provided)

** Document Compilation Issues

*** LaTeX Compilation Fails

1. Check =*TeX Help*= buffer for errors
2. Ensure LuaLaTeX installed:
   #+begin_src shell
   which lualatex
   #+end_src
3. View log: =C-c C-l=

*** ConTeXt Compilation Fails

1. ConTeXt is included in =texlive.combined.scheme-full=:
   #+begin_src shell
   which context
   #+end_src
2. Check font access:
   #+begin_src shell
   echo $OSFONTDIR
   #+end_src

*** Typst Compilation Fails

1. Ensure Typst installed:
   #+begin_src shell
   which typst
   #+end_src
2. Check error output in compilation buffer

*** Typst LSP Not Working

1. Ensure tinymist installed:
   #+begin_src shell
   which tinymist
   #+end_src
2. Start eglot manually: =M-x eglot=
3. Check =*eglot-events*= buffer for errors

*** Typst Tree-Sitter Warnings

Byte-compilation warnings from =typst-ts-mode= are suppressed in the config. If you see warnings about =treesit-auto-recipe-list= or =eglot--all-major-modes=, they are harmless and do not affect functionality.

** PDF Issues

*** PDF Not Opening in Emacs

PDF-tools is installed via Nix. If issues persist:
1. Check =epdfinfo= binary: =M-x pdf-tools-install RET=
2. Ensure =poppler= is installed in =emacs.nix=

*** PDF Renders Incorrectly

Ensure =poppler= and =poppler-utils= are installed (provided by =emacs.nix=).

** Org-Roam Issues

*** Database Errors

: M-x org-roam-db-sync RET

*** Nodes Not Appearing

1. Check file has =#+title:= property
2. Ensure file is in =~/Documents/roam/=
3. Rebuild database: =M-x org-roam-db-sync=

** Seforim Library Issues

*** "plocate not found" or "DB not readable"

1. Ensure user is in =plocate= group:
   #+begin_src shell
   groups | grep plocate
   #+end_src
2. If not, re-login after =nixos-rebuild switch= (group changes require re-login)
3. Check database exists:
   #+begin_src shell
   ls -la /var/cache/locatedb
   #+end_src

*** Recoll Returns No Results

1. Check recoll config:
   #+begin_src shell
   cat ~/.recoll/recoll.conf
   #+end_src
2. Run initial indexing:
   #+begin_src shell
   recollindex
   #+end_src
3. Or from Emacs: =C-c S I=

*** Slow Search

1. Build indexes: =C-c S I=
2. Use indexed search (=C-c S f=, =C-c S s=) instead of fallbacks

*** No Search Results for Hebrew

Check files are UTF-8 encoded:
#+begin_src shell
file -i yourfile.org
#+end_src

#+begin_src shell
iconv -f ISO-8859-8 -t UTF-8 oldfile.org > newfile.org
#+end_src
