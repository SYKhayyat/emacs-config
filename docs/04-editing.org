* Purpose

Advanced editing features:
- Undo tree visualization
- Multiple cursors
- Expand region
- Move text
- Focused writing mode
- Smart editing commands

| Key       | Command                  | Description            |
|-----------+--------------------------+------------------------|

| ~C-c W~   | my/set-focused-width     | Set column width       |

* Focused Writing Mode

Centers text at 80 columns (configurable). Good for prose writing.

Toggle: ~C-c w~

Change width: ~C-c W~ then enter number (e.g., 100)

* Configuration Options

** Undo limits

#+begin_src emacs-lisp :tangle no
(setq undo-limit (* 80 1024 1024))         ; 80 MB
(setq undo-strong-limit (* 120 1024 1024)) ; 120 MB
#+end_src

** Focused writing width

#+begin_src emacs-lisp :tangle no
(setq-default visual-fill-column-width 100)
#+end_src

* Dependencies

- 00-core
- 01-ui
- visual-fill-column package

* Troubleshooting

** Focused writing not working

Check package: ~M-: (featurep 'visual-fill-column)~

If nil, add to ~default.nix~ and rebuild.

** Undo tree history not saving

Check directory exists: ~ls ~/.cache/emacs/undo-tree-history/~
