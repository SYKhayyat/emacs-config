#+begin_src emacs-lisp
;; 1. THE NIXOS CRASH VACCINE
;; This MUST come before (use-package pdf-tools) to stop the void-function error.
(defun pdf-occur-global-minor-mode (&optional arg)
(interactive)
(message "NixOS pdf-tools hook bypass"))

;; 2. THE GIBBERISH PREVENTER
;; Tell Emacs to use pdf-view-mode for all PDF files immediately
(setq auto-mode-alist (append '(("\.pdf\'" . pdf-view-mode)) auto-mode-alist))

(use-package pdf-tools
:ensure t
:mode ("\.pdf\'" . pdf-view-mode)
:init
;; Find the Nix-provided binary
(setq pdf-info-epdfinfo-program (executable-find "epdfinfo"))
:config
;; NixOS standard initialization (Manual start)
(pdf-info-initialize)
(pdf-cache-install)
(pdf-history-install)

;; Viewer Settings
(setq-default pdf-view-display-size 'fit-page)
(setq pdf-view-use-scaling t)

;; Midnight Mode (Amber/Wheat on Charcoal)
(setq pdf-view-midnight-colors '("#dcdccc" . "#1a1a1a"))
(add-hook 'pdf-view-mode-hook #'pdf-view-midnight-minor-mode)

;; --- DAF NAVIGATION FUNCTIONS ---

(defun seforim-pdf-goto-page (page)
"Jump to a specific page number."
(interactive "nGo to page: ")
(pdf-view-goto-page page))

(defun seforim-pdf-goto-daf (daf-num amud)
"Jump to a Daf in Vilna Gemara PDF. Assumes page 3 is Daf 2a."
(interactive "nDaf Number: \nsAmud (a or b): ")
(let* ((base-page (* (- daf-num 2) 2))
(offset (if (string= amud "a") 3 4))
(target-page (+ base-page offset)))
(pdf-view-goto-page target-page)))

;; Bind keys inside the viewer
(with-eval-after-load 'pdf-view
(define-key pdf-view-mode-map (kbd "g") 'seforim-pdf-goto-page)
(define-key pdf-view-mode-map (kbd "G") 'seforim-pdf-goto-daf)
(define-key pdf-view-mode-map (kbd "o") 'pdf-outline)
(define-key pdf-view-mode-map (kbd "s s") 'pdf-occur)))
#+end_src

    Troubleshooting

** If files still show as gibberish
Run M-x pdf-view-mode. If that works, then another config file is loading after this one and stealing the .pdf association.

** If the error "void-function" persists
You may need to run home-manager switch or nixos-rebuild to ensure the new org file is tangled into your config directory.

Why did I change it this way?

    Removed Global Properties: Your seforim file starts directly with * Purpose. I removed the #+TITLE and #+PROPERTY headers I added earlier, which were likely confusing your Nix/Org tangling script.

    Simplified the Code Block: The code block now looks exactly like the ones in your working files.

    The "Vaccine" Placement: I kept the (defun pdf-occur-global-minor-mode ...) at the very top of the code block. This is essential for NixOS because the Nix-provided pdf-tools tries to call that function the moment the package is loaded.

    Auto-mode Append: I used (setq auto-mode-alist (append ...)) to ensure our PDF rule is at the absolute top of the list, so Emacs sees it first.
