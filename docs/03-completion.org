#+TITLE: 03-completion Module
#+STARTUP: overview

* Purpose

Modern completion framework:
- Vertical completion (Vertico)
- Fuzzy matching (Orderless)
- Rich annotations (Marginalia)
- Search and navigation (Consult)
- In-buffer completion (Corfu)
- Actions on candidates (Embark)
- Spell checking (Jinx)

* Packages Used

| Package        | Purpose                         |
|----------------+---------------------------------|
| vertico        | Vertical completion UI          |
| orderless      | Fuzzy/flexible matching         |
| marginalia     | Annotations in minibuffer       |
| consult        | Enhanced search commands        |
| corfu          | Popup completion in buffer      |
| embark         | Actions on completion candidates|
| embark-consult | Embark + Consult integration    |
| which-key      | Show available keybindings      |
| helpful        | Better help buffers             |
| jinx           | Fast spell checker              |

* Configuration Options

** Vertico count

#+begin_src emacs-lisp :tangle no
(setq vertico-count 20)  ; Show 20 candidates (default 15)
#+end_src

** Corfu auto-completion

#+begin_src emacs-lisp :tangle no
(setq corfu-auto-delay 0.5)   ; Wait 0.5s before popup
(setq corfu-auto-prefix 3)    ; Need 3 chars to trigger
#+end_src

* Troubleshooting

** Completion not showing

Check vertico is active: ~M-: vertico-mode~

** Ripgrep not working

Ensure ripgrep is installed: ~which rg~

** Spell check errors

Jinx needs dictionaries. Check:
~M-: jinx-languages~

Should show ~"en_US he_IL"~.
