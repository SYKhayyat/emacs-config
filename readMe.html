1. Installation

1.1. NixOS Configuration

  1. Copy emacs-packages.nix to /etc/nixos/

  2. Edit /etc/nixos/configuration.nix and add: 

    imports = [
  ./hardware-configuration.nix
  ./emacs-packages.nix
];

  3. Rebuild: 

    sudo nixos-rebuild switch

1.2. Emacs Configuration

  1. Create directory: 

    mkdir -p ~/.emacs.d

  2. Copy files: 

    cp config.org ~/.emacs.d/
cp init.el ~/.emacs.d/

  3. Create required directories: 

    mkdir -p ~/Documents/roam
mkdir -p ~/Documents/org
touch ~/Documents/bibliography.bib
  4. Start Emacs and wait for packages to install

1.3. First Run Tasks

After first launch:

  1. Install icon fonts: 

    M-x all-the-icons-install-fonts RET

  2. Initialize org-roam database: 

    M-x org-roam-db-sync RET

3. Hebrew and RTL Support

3.1. How Direction Works

The config automatically sets direction per major mode:

Mode Type Default Direction
Org, LaTeX, text modes RTL (Hebrew)
Programming modes LTR (English)
Other modes Auto-detect

You can always override manually with the keybindings below.

3.2. Switching Languages

Keybinding Action
F9 Toggle input method (Hebrew ↔ English)
C-c d Toggle text direction (RTL ↔ LTR)
C-c r Force RTL direction
C-c l Force LTR direction
C-c D Direction controls menu (hydra)

3.3. Visual Indicators

The modeline shows current state:

  • [RTL עב] - Hebrew mode, right-to-left
  • [LTR EN] - English mode, left-to-right

3.4. Best Practices

  1. Hebrew documents: Automatically RTL (Org, LaTeX, text modes)
  2. English documents: Use C-c l for LTR, or it auto-detects
  3. Mixed documents: Use C-c d to toggle as needed
  4. Code: Automatically LTR (prog-mode)

3.5. Spell Checking

Spell checking uses Flyspell with Hunspell. Switch between languages manually:

Keybinding Action
C-c s e Switch to English
C-c s h Switch to Hebrew
M-$ Correct word at point
i Add word to personal dict

When a correctly-spelled word is flagged (e.g., Hebrew word while in English mode), press i to add it to your personal dictionary (~/.hunspell_personal).

Spell checking is active in:

  • All text/prose modes (Org, LaTeX, Markdown, etc.)
  • Comments and strings in programming modes

7. Nested Footnotes in LaTeX

7.1. Overview

The bigfoot package provides multiple footnote levels. Each level appears in its own separate block at the bottom of the page.

7.2. Method 1: Simple Footnotes (Non-Nested)

Use \footnoteB{}, \footnoteC{}, etc. directly from body text. Each level gets its own block:

Result at page bottom: 

─────────────────────────────
¹ First level footnote.

─────────────────────────────
¹ Second level, appears in separate block.

7.3. Method 2: True Nesting (Footnote Within Footnote)

To place a footnote inside another footnote, use \footnotemarkX + \footnotetextX{}:

Result at page bottom: 

─────────────────────────────
¹ This is the first-level footnote. It discusses a concept¹
  that needs further explanation.

─────────────────────────────
¹ This second-level footnote appears in its own separate block
  at the bottom of the page, below the first-level footnotes.
  It can even contain another level¹.

─────────────────────────────
¹ Third level footnote, in its own block.

7.4. Footnote Levels Reference

Command Level Use
\footnote{} 1 Normal footnotes
\footnoteB{} 2 Second level
\footnoteC{} 3 Third level
\footnoteD{} 4 Fourth level
\footnoteE{} 5 Fifth level
\footnoteF{} 6 Sixth level
\footnoteG{} 7 Seventh level
\footnoteH{} 8 Eighth level
\footnoteI{} 9 Ninth level
\footnoteJ{} 10 Tenth level

For nesting, use:

  • \footnotemarkB through \footnotemarkJ (places the superscript)
  • \footnotetextB{} through \footnotetextJ{} (places the text in its block)

8. ConTeXt

8.1. What is ConTeXt?

ConTeXt is a TeX-based document system with:

  • Native RTL/Hebrew support (no packages needed)
  • Built-in local footnotes (nested footnotes in separate blocks)
  • Excellent typography
  • "Batteries included" philosophy

8.2. Creating a ConTeXt Document

Use C-c h x to create a Hebrew ConTeXt document, or create manually: 

\mainlanguage[he]
\setupalign[r2l]
\definefontfamily[hebrew][rm][David CLM]
\definefontfamily[hebrew][ss][Nachlieli CLM]
\definefontfamily[hebrew][tt][Miriam Mono CLM]
\setupbodyfont[hebrew]

\starttext

\startsection[title={מבוא}]

טקסט בעברית.

\stopsection

\stoptext

8.3. Compiling ConTeXt

In Emacs:

  1. Press C-c C-c
  2. Type ConTeXt and press RET

Or from command line: 

context myfile.tex

8.4. ConTeXt Sectioning

Command Description
\startpart[title={...}] Part
\startchapter[title={...}] Chapter
\startsection[title={...}] Section
\startsubsection[title={...}] Subsection
\startsubsubsection[title={...}] Subsubsection

Each must be closed with \stop...

8.5. Local Footnotes in ConTeXt

ConTeXt's killer feature: footnotes that appear at the bottom of their parent footnote, not at the bottom of the page. 

זהו טקסט ראשי.\footnote{
  זוהי הערת שוליים ראשונה.
  \startlocalfootnotes
  מונח כלשהו.\localfootnote{
    הערה מקוננת — מופיעה בתחתית ההערה הראשונה, לא בתחתית העמוד.
    \startlocalfootnotes
    עוד מונח.\localfootnote{
      הערה שלישית — בתחתית ההערה השנייה.
    }
    \placelocalfootnotes
    \stoplocalfootnotes
  }
  \placelocalfootnotes
  \stoplocalfootnotes
}

Result:

  • Level 1 footnote → bottom of page
  • Level 2 footnote → bottom of level 1 block
  • Level 3 footnote → bottom of level 2 block

Use C-c P then f to insert a local footnote structure.

9.6. Nested Footnotes in Typst

9.6.1. The Problem

By default, Typst doesn't allow you to place a #footnote inside another #footnote. If you try, you'll get an error because Typst tries to render all footnote entries inline in a single flow at the bottom of the page.

9.6.2. The Solution

Add this show rule at the top of your document: 

#show footnote.entry: it => {
  block(it)
}

9.6.3. Why It Works

By wrapping each footnote.entry in a block():

  1. Isolates each footnote entry into its own independent layout container
  2. Breaks the layout dependency between parent and child footnotes
  3. Each footnote can now independently place its own sub-footnotes

9.6.4. Full Working Example

// This is the critical line: wrap each footnote entry in its own block
#show footnote.entry: it => {
  block(it)
}

This is body text with a footnote.#footnote[
  This is the first-level footnote, and it contains
  another footnote inside it.#footnote[
    This is a second-level (nested) footnote! You can even
    go deeper.#footnote[
      Third level nested footnote.
    ]
  ]
]

More body text here.#footnote[A normal, non-nested footnote for comparison.]

Result at page bottom: 

──────────────────────────────────────
¹ This is the first-level footnote, and it contains
  another footnote inside it.²
² This is a second-level (nested) footnote! You can even
  go deeper.³
³ Third level nested footnote.
⁴ A normal, non-nested footnote for comparison.

Each footnote gets its own numbered entry, laid out sequentially at the page bottom.

9.6.5. Hebrew Example

#set text(lang: "he", font: "David CLM")
#set page(flipped: true)

// Enable nested footnotes
#show footnote.entry: it => {
  block(it)
}

= מבוא

זהו טקסט ראשי עם הערת שוליים.#footnote[
  זוהי הערת שוליים ראשונה, המכילה הערה נוספת.#footnote[
    זוהי הערת שוליים מקוננת! אפשר להמשיך לעומק.#footnote[
      הערת שוליים ברמה שלישית.
    ]
  ]
]

9.6.6. Optional Styling

You can add styling while keeping the block wrapper: 

#show footnote.entry: it => {
  block({
    set text(size: 9pt)
    it
  })
}

9.6.7. Caveats

  • Numbering is flat: All footnotes share one sequential counter (1, 2, 3…). Typst doesn't distinguish "levels."
  • All appear at page bottom: Nested footnotes don't appear indented under their parent — they're sequential entries.
  • Deep nesting: 2–3 levels work well; extremely deep nesting may be confusing.

9.6.8. Comparison with LaTeX/ConTeXt

Feature LaTeX (bigfoot) ConTeXt Typst
Separate blocks ✓ Each level ✓ Hierarchical ✗ Sequential
Numbering Per-level Per-level Flat (shared)
True hierarchy ✓ ✓ ✗
Ease of use Medium Easy Easy
Setup required Package + declare None One show rule

10. Nested Footnotes Comparison

Feature LaTeX (bigfoot) ConTeXt Typst
Setup required Package + declare None (built-in) One show rule
Syntax \footnotemarkB etc. \localfootnote{} #footnote[] inside
Separate visual blocks ✓ Yes ✓ Yes (hierarchical) ✗ No (sequential)
Numbering Per-level Per-level Flat (all share)
Max levels Unlimited Unlimited ~3 practical
Best for Journals, academic Books, complex docs Quick iteration

Recommendations:

  • For true hierarchical footnotes in separate blocks: ConTeXt
  • For separate blocks with journal compatibility: LaTeX with bigfoot
  • For fast iteration with acceptable nesting: Typst

13.4. Electric Pairs (Auto-closing Brackets)

Electric pairs (auto-inserting matching (), {}, "", etc.) are enabled only in:

  • Programming modes (Python, Rust, Java, etc.)
  • LaTeX mode
  • ConTeXt mode
  • Typst mode
  • Org source block editing (via C-c ')

They are disabled in prose modes (Org, Markdown, plain text) to avoid interfering with Hebrew writing.

16. Adding New Packages

16.1. Method 1: Edit config.org (Recommended)

  1. Open ~/.emacs.d/config.org
  2. Find appropriate section or create new heading
  3. Add a use-package block:
** My New Package

(use-package package-name
  :config
  ;; Configuration here
  )
#+end_src
  1. Save the file
  2. Either:
    • Restart Emacs, OR
    • Place cursor in the block and press C-c C-c to evaluate

16.2. Method 2: Quick Install (Temporary)

  1. M-x package-install RET
  2. Type package name
  3. Press RET

Note: This won't persist after restart unless added to config.org.

16.3. Use-Package Syntax Reference

(use-package package-name
  :ensure t                      ; Install if not present
  :hook (mode-name . function)   ; Add hooks
  :bind (("C-c x" . command))    ; Key bindings
  :config                        ; Run after loading
  (setq some-variable value)
  :custom                        ; Set custom variables
  (variable-name value)
  :init                          ; Run before loading
  (some-setup-function))

16.4. Common Use-Package Keywords

Keyword Purpose
:ensure Install package if missing
:hook Add function to mode hook
:bind Define keybindings
:config Run code after package loads
:init Run code before package loads
:custom Set customization variables
:after Load after specified package
:defer Defer loading (lazy load)
:mode Associate with file extensions

16.5. Adding System Packages (NixOS)

  1. Edit /etc/nixos/emacs-packages.nix
  2. Add packages to environment.systemPackages:
environment.systemPackages = with pkgs; [
  # ... existing packages ...
  new-package-name
];
  1. Rebuild:
sudo nixos-rebuild switch

19. Troubleshooting

19.1. Packages Not Installing

M-x package-refresh-contents RET

Then restart Emacs.

19.2. Hebrew Not Displaying

  1. Check fonts installed: 

    fc-list | grep -i hebrew

  2. Check input method: 

    C-h v current-input-method RET

  3. Check direction: 

    C-h v bidi-paragraph-direction RET

19.3. Hebrew Footnotes Showing as LTR in Org

Use C-c h f to fix all existing footnotes in the buffer. New footnotes are fixed automatically.

19.4. PDF Not Opening in Emacs

Run once: 

M-x pdf-tools-install RET

19.5. Org-Roam Database Errors

M-x org-roam-db-sync RET

19.6. LaTeX Compilation Fails

  1. Check *TeX Help* buffer for errors

  2. Ensure LuaLaTeX installed: 

    which lualatex
  3. Check log: C-c C-l

19.7. ConTeXt Compilation Fails

  1. Ensure ConTeXt installed: 

    which context

  2. Check font access: 

    echo $OSFONTDIR

19.8. Typst Compilation Fails

  1. Ensure Typst installed: 

    which typst
  2. Check for syntax errors in output

19.9. Typst LSP Not Working

  1. Ensure tinymist installed: 

    which tinymist
  2. Start eglot manually: M-x eglot

19.10. Spell Check Not Working

  1. Check hunspell: 

    which hunspell

  2. Check dictionaries: 

    hunspell -D
  3. Verify both en_US and he_IL appear in available dictionaries

  4. Check DICPATH environment variable: 

    echo $DICPATH
  5. Switch to correct language: C-c s e for English, C-c s h for Hebrew
  6. If a word is incorrectly flagged, press i to add it to personal dictionary

19.11. Slow Startup

First startup is slow due to package installation. If still slow:

  1. Check *Messages* buffer
  2. Run: emacs --debug-init

19.12. Config Changes Not Taking Effect

After editing config.org:

  1. Delete ~/.emacs.d/config.el
  2. Restart Emacs

Or manually tangle: 

M-x org-babel-tangle RET
